```bash

./start.sh --offline 20   # 결과를 파일로 (검증에 제일 빠르다)
```

고친 뒤에는 최소한 <두 경로>가 통과해야 합니다.

## 파일과 책임

| 파일 | 책임 | 주의 |
|---|---|---|
| `<패키지>/settings.py` | **숫자의 유일한 출처** | 다른 파일에 숫자를 하드코딩하지 않는다 |

## 깨뜨리면 안 되는 것

1. **인터넷 없이 떠야 한다.** CDN·외부 폰트·외부 스크립트를 넣지 않는다.
2. **없어도 돌아가야 한다.** 장비나 엔진이 빠져도 멈추지 않는다.
3. **숫자는 `settings.py` 에.**
4. **주석과 문서는 한국어.** 긴 대시 대신 쉼표와 마침표.
5. **큰 자료와 GPL 엔진은 벤더링하지 않는다.** 설치가 받아 오고 별도 프로세스로 쓴다.
6. **라이선스.** 소스 공개다. 오픈소스라고 부르지 않는다.
