## 4. 관객의 경험

- 처음 마주치는 것: 전시장에 들어와 이 작품을 처음 봤을 때 보이고 들리는 것
- 관객이 하는 일: 보기만 한다 / 몸을 움직인다 / 다가간다 / 만진다 / 소리를 낸다 / 물건을 옮긴다 / 글을 쓴다 중에서, 또는 직접
- 작품이 돌려주는 것: 관객이 그 일을 하면 무엇이 바뀌나
- 머무는 시간: 한 사람이 대략 몇 분
- 한 번에 몇 명: 혼자 / 둘셋 / 여럿이 동시에
- 안내가 필요한가: 설명 없이 알아챌 수 있나, 안내문이나 지킴이의 말이 필요한가

## 8. 전시 조건

전시는 12월 19일(토) 사상인디스테이션입니다. 설치는 12월 14일~18일입니다.

- 놓이는 곳과 크기: 벽 / 바닥 / 좌대 / 천장에 매달기, 가로 × 세로 × 높이
- 전원: 콘센트 몇 구, 오래 켜 두면 뜨거워지는 장비가 있나
- 인터넷: 필요 없음 / 와이파이면 됨 / 유선이 필요함
- 빛: 어두워야 하나, 밝아도 되나
- 소리: 스피커 / 헤드폰, 옆 작품으로 소리가 새도 되나
- 재단 공통 기자재에서 빌릴 것: 프로젝터, 모니터, 스피커 중 무엇을 몇 대
- 직접 가져올 것:
- 켜고 끄기: 아침에 켜고 저녁에 끄는 방법, 멈추면 다시 켜는 방법
- 지킴이: 필요 없음 / 가끔 봐 주면 됨 / 늘 옆에 있어야 함
- 안전: 바닥의 전선, 관객이 만지는 부분, 넘어질 수 있는 것
