# tools — 소프트웨어별 도구 번들

아트앤테크 작업에 쓰는 **소프트웨어 하나당 폴더 하나**입니다.
한 폴더 안에 그 소프트웨어로 작업하는 데 필요한 것이 모여 있습니다.

```text
tools/<소프트웨어>/
├── server/       MCP 서버 (선택) — Cursor·Claude·Codex 가 이 도구를 다루게 하는 부분
├── baseline/     시작점 프로젝트 (선택) — 작가가 여기서 출발해 작품을 만든다
├── README.md     이 도구로 무엇을 할 수 있는지 (한국어)
└── NOTICE.md     이 도구에 포함된 제3자 구성요소와 라이선스
```

`server` 와 `baseline` 은 **둘 중 하나만 있어도 됩니다.**
Arduino 처럼 베이스라인이 핵심인 도구가 있고, GitHub 처럼 서버만 있는 도구가 있습니다.

## 폴더 이름

**소프트웨어의 통용 이름을 소문자로** 씁니다. 역할이나 수업 회차가 아닙니다.

| 좋음 | 나쁨 | 이유 |
|---|---|---|
| `p5js` | `web-graphics` | 역할로 부르면 같은 도구가 여러 이름을 갖는다 |
| `arduino` | `session-06` | 회차는 바뀌고 도구는 남는다 |
| `unity` | `game-engine` | 다른 엔진이 들어오면 이름이 무너진다 |

MCP 서버 키도 같은 이름을 씁니다: `opencircuit-<소프트웨어>`

## 자족성

각 폴더는 **혼자 떼어내도 말이 되어야** 합니다.
누군가 Arduino 부분만 필요하다면 `tools/arduino/` 만 보면 되도록 유지합니다.
그래서 README 와 NOTICE 가 도구마다 따로 있습니다.

## 현재 상태

| 도구 | server | baseline | 상태 |
|---|---|---|---|
| `p5js` | — | 예정 | 웹 그래픽·사운드 베이스라인 |
| `github` | 예정 | — | 레포 생성·Pages 배포 |
| `apiframe` | 예정 | — | 이미지·영상 생성 |
| `unity` | — | 예정 | Unity 6000.3.13f1 |
| `arduino` | — | 예정 | 서보·센서 |
| `blender` | — | 예정 | Unity 파이프라인 보조 |

소프트웨어에 종속되지 않는 것(설치 검증 등)은 [`core/`](../core) 에 둡니다.
