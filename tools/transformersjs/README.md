# transformers.js — 웹캠에서 문장 하나

카메라에 보이는 것을 브라우저 안의 작은 모델이 **문장 하나**로 말합니다.
그 문장을 복사해 Cursor에게 주면 APIFrame 프롬프트가 됩니다.

서버로 이미지가 올라가지 않습니다. 모델은 이 컴퓨터 안에서 돕니다.

## 오프라인 원칙의 예외

[architecture.md](../../docs/architecture.md) 는 「기동에 네트워크가 필요 없게」를 원칙으로 둡니다.
이 베이스라인은 **모델 가중치를 처음 열 때 내려받으므로 그 원칙의 예외**입니다.

수업 시작 직후 운영자 페이지를 미리 열어 두면, 그 주소에서는 두 번째부터 빠릅니다.
캐시는 **오리진(주소) 단위**입니다. 운영자 페이지에서 받아 둬도 수강생이
자기 GitHub Pages 주소를 열면 **다시 받습니다.**

## 쓰는 법

1. `baseline/index.html` 을 브라우저로 엽니다. (`file://` 보다 로컬 서버나 미리보기가 안전합니다.)
2. 「모델을 받는 중입니다 — 처음 한 번만, 약 500MB」가 사라질 때까지 기다립니다.
3. 재료를 웹캠 앞에 두고 「이 장면을 문장으로」를 누릅니다.
4. 나온 문장 옆 **복사**를 누른 뒤 Cursor에게 붙여 이미지·영상·음악을 만듭니다.

모델이 안 뜨거나 문장이 마음에 안 들면, **아래 칸에 직접 쓰세요.**
이 페이지는 어떤 경우에도 다음 단계를 막지 않습니다.

WebGPU 가 없는 컴퓨터는 느린 모드(WASM)로 돕니다. 화면에 그 사실을 알려 줍니다.

## 라이선스

라이브러리는 Apache-2.0 로 `baseline/lib/` 에 벤더링되어 있습니다.
모델 가중치는 벤더링하지 않습니다. 자세한 표는 [NOTICE.md](NOTICE.md).
