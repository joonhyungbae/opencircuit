# Processing · 카메라가 본 것을 코드로 다루기

3회차(2026년 9월 5일, 이정섭 강사) 수업에서 한 것을 집에서 다시 해 보는 스케치들입니다.
수업에서는 Processing 에 들어 있는 웹캠 예제와 BlobDetection 예제를 변형해 손전등을 찾고 그 자리에 패턴을 입혔습니다.
그 순서를 1단계부터 5단계까지 파일 하나씩으로 나눠 두었습니다. 한 단계에 하나씩만 늘어나므로 어디서 무엇이 생기는지 보입니다.

Optical Flow 는 수업에서 개념까지 듣고 코드는 운영자가 따로 만들어 돌려 봤습니다. 그 코드도 여기 있습니다.

## 준비

1. **Processing 4 설치.** 화면 사진과 함께 정리한 안내가 [위키](https://opencircuit.club/wiki/tools/processing)에 있습니다.
2. **라이브러리.** Processing 을 열고 `Sketch` → `Import Library` → `Manage Libraries` 에서 이름으로 찾아 설치합니다.
   수업 전에 설치한 네 개 중 셋을 씁니다.
   - `Video` (Video Library for Processing 4)
   - `BlobDetection` (Julien 'v3ga' Gachadoat) · 1단계부터 5단계까지
   - `OpenCV for Processing` · OpenCVCamDemo 와 OpticalFlow
3. **macOS 카메라 권한.** 처음 실행하면 물어봅니다. 거절했다면 시스템 설정 → 개인정보 보호 및 보안 → 카메라에서 Processing 을 켭니다.

라이브러리를 설치한 뒤에는 스케치 창을 닫았다가 다시 여세요. 열어 둔 채로 설치하면 인식하지 못합니다.

## 여는 법

Processing 은 스케치가 같은 이름의 폴더 안에 있기를 바랍니다. 폴더째로 받아서 그대로 여세요.
열고 왼쪽 위 ▶ 를 누르면 창이 뜹니다. 멈출 때는 ■ 입니다.

## 1단계부터 5단계까지

수업에서 간 순서 그대로입니다. 1단계부터 차례로 열어 보시면 됩니다.

| 폴더 | 무엇을 하나 | 새로 생기는 것 |
|---|---|---|
| `Step1Webcam` | 웹캠을 열어 내 얼굴이 창에 나온다 | 카메라 열기 |
| `Step2Blobs` | 밝은 곳에 테두리가 그려진다 | BlobDetection |
| `Step3Threshold` | 문턱값을 올려 손전등만 남긴다 | 위·아래 키로 문턱값, 잡힌 자리의 좌표 |
| `Step4Pattern` | 잡힌 자리에 패턴이 그려진다 | `drawPattern()` 과 지나간 자리 |
| `Step5MakeItYours` | 찾는 대상과 패턴을 바꾼다 | 밝은 것·어두운 것·고른 색, 패턴 셋 |

### 설문에서 막힐 것 같다고 하신 것이 어디에 있나

- **문턱값을 어디서 얼마로 바꾸는지** → `Step3Threshold` 의 `threshold` 입니다. 위·아래 키로 올렸다 내렸다 하면서 손전등만 남는 값을 찾습니다. 방 밝기마다 다릅니다. `B` 를 누르면 찾는 쪽이 실제로 보고 있는 작은 그림이 뜹니다.
- **잡힌 자리의 좌표를 코드 어디서 가져오는지** → 블롭의 `b.x` 와 `b.y` 입니다. 0~1 로 오기 때문에 화면 크기를 곱해서 씁니다. `Step3Threshold` 가 그 값을 화면에 찍어 줍니다.
- **패턴을 그리는 코드를 어디에 넣는지** → `Step4Pattern` 의 `drawPattern()` 안입니다. 그 함수만 고치면 나머지는 건드리지 않아도 됩니다.
- **오류가 났을 때 무엇을 고쳐야 하는지** → 아래 「안 될 때」를 보세요.

## OpenCVCamDemo

왼쪽에 카메라 원본, 오른쪽에 처리 결과가 나옵니다. 숫자키로 처리 방식을 바꿉니다.
수업에서 이름만 지나간 것들이 무엇인지 눈으로 보는 데 씁니다.

| 키 | 무엇을 하나 |
|---|---|
| `1` | 원본 그대로 |
| `2` | 흑백 |
| `3` | 캐니 엣지 (윤곽선만 남기기) |
| `4` | 이진화 (문턱값보다 밝은 곳만 흰색) |
| `5` | 외곽선 검출 |
| `6` | 얼굴 검출 |
| `7` | Optical Flow |
| `8` | 배경 차분 (움직인 곳만) |

`위`·`아래` 화살표로 지금 모드의 값을 바꾸고, `s` 로 화면을 PNG 로 저장합니다.
4번과 5번이 1단계부터 5단계까지에서 한 것을 OpenCV 쪽 도구로 하는 방법입니다. 같은 일을 하는 길이 하나가 아닙니다.

## OpticalFlow

화면의 어느 자리가 어느 쪽으로 얼마나 움직였는지 계산해서 벡터와 색으로 보여 줍니다.
입자를 뿌려 흐름을 따라가게 할 수도 있습니다.

| 키 | 무엇을 하나 |
|---|---|
| `V` | 보기 전환 (벡터 / 색 / 둘 다) |
| `P` | 입자 켜고 끄기 |
| `스페이스` | 일시정지 |
| `R` | 입자 다시 뿌리기 |
| `+` `-` | 벡터 간격 |

바꿔 볼 값은 코드 위쪽에 모아 두었습니다.
`PROC_W` 와 `PROC_H` 는 계산 해상도라 낮출수록 빨라지고 거칠어집니다. `TRACER_COUNT` 는 입자 수입니다.
`mag < 0.4` 처럼 적힌 숫자는 이보다 작은 움직임을 무시한다는 뜻이라, 손 흔드는 정도만 잡고 싶으면 올립니다.

## 안 될 때

- **「카메라 프레임 대기 중」에서 멈춘다.** 다른 앱이 카메라를 쓰고 있는지 봅니다.
  아래 검은 칸(콘솔)에 카메라 목록이 번호와 함께 찍히므로, `setup()` 의 주석대로 다른 카메라를 골라 열 수 있습니다.
- **`The package "blobDetection" does not exist`.** 라이브러리가 아직 없습니다. Manage Libraries 에서 이름을 다시 확인하고 설치한 뒤 스케치를 닫았다 다시 엽니다.
- **「OpenCV를 시작하지 못했습니다」가 뜬다.** 같은 이유입니다. OpenCV for Processing 은 0.7 이상이어야 합니다.
- **아무것도 안 잡힌다.** 문턱값이 너무 높습니다. 아래 화살표로 내리면서 보세요. 반대로 방이 밝으면 벽까지 잡히므로 올립니다.
- **그 밖의 오류.** 콘솔에 뜬 빨간 글자를 그대로 복사해 Cursor 에 붙여 넣고 무엇을 고치면 되는지 물어보세요.
  화면 사진 한 장과 무엇을 하다가 그렇게 됐는지 한 줄이면 카톡으로 물어보셔도 됩니다.
