# 스터디 슬라이드

이 폴더가 내 발표입니다. **`src/deck.json` 만 고치면 됩니다.** 코드는 건드리지 않아도 됩니다.

```bash
npm install
npm run dev
```

또는 저장소 루트에서 `./web.sh <이 폴더>` 로 띄웁니다.

## 여기를 바꾸세요

- **내용** → `src/deck.json`
- **그림** → `public/` 에 두고, 주소는 `/파일이름.jpg` 처럼 적습니다. 원본을 줄이지 마세요.
- **유튜브** → `{ "kind": "youtube", "src": "https://youtu.be/…" }`

## 조작

| 키 | 하는 일 |
|---|---|
| ← → · 스페이스 · PageUp/Down | 장 넘기기 |
| 아래 막대의 버튼 | 같은 일 |
| F | 전체 화면 |
| 주소 `#7` | 7번째 장으로 바로 열기 |

화면을 클릭해서는 넘어가지 않습니다. 키보드나 클리커를 씁니다.

## 블록

`deck.json` 의 `blocks` 에 넣는 종류입니다. 예는 템플릿 덱에 있습니다.

| kind | 무엇 | 옵션 |
|---|---|---|
| `lead` | 테두리 친 한 문단 | `text` |
| `big` | 큰 글자 한 줄 | `text`, `sub` |
| `bullets` | 점 목록 | `items` |
| `cards` | 제목 있는 카드 | `items[{title, lines 또는 text}]`, `cols` 1·2·3 (기본 2) |
| `steps` | 단계 카드 | `items[{no, label, desc, color}]`, `stack: true` 면 세로로 쌓음(시간표) |
| `table` | 표 | `head`, `rows` |
| `qa` | 질문·답 | `items[{q, a}]` |
| `note` | 옅은 배경 메모 | `text`, `tone: "warn"` 이면 노란 배경 |
| `figure` | 그림 한 장 | `src`, `caption`, `size: "lg"` 면 칸을 가득 채움 |
| `youtube` | 유튜브 | `src`(watch·youtu.be·shorts 주소), `caption` |
| `row` | 왼쪽·오른쪽 나눔 | `left`, `right` 에 블록 배열 |

글 안에서 `**굵게**` 와 주소 자동 링크가 됩니다.

## 이 칸이 어디서 왔나 — `source`

각 장에 `source` 를 달면 제목 옆에 배지가 뜹니다. **논문이 적은 것과 발표자가 채운 것을
구분하는 자리**입니다. 안 달면 배지가 안 뜹니다.

| `source` | 배지 | 언제 |
|---|---|---|
| `paper` | 논문에 적힘 | 논문이 적었다 |
| `inferred` | 논문에서 유추 | 논문에서 유추했다. 유추임을 문장에도 밝힙니다 |
| `absent` | **논문에 적히지 않음** | 논문이 안 적었다. 노란 배지 |
| `reader` | 발표자가 채움 | 논문 밖에서 알아낸 것 |
| `na` | 해당 없음 | 이 작품에 해당하지 않는다 |

`absent` 는 **「없었다」가 아닙니다.** 논문이 안 적었을 뿐, 있었는지 없었는지는 모릅니다.
「없었다 · 안 했다 · 사용하지 않았다」로 바꿔 적지 마세요. 사실이 아닌 말이 됩니다.

⑧번 장이 이 용례로 들어 있습니다.
표지는 `cover` 입니다. 섹션 색은 `"212 80% 45%"` 처럼 HSL 세 숫자만 적습니다.
