# 작품 예제 저장소 규칙

작가가 받아서 고쳐 쓰는 예제는 저장소 하나에 하나씩 만듭니다. 이 문서는 그 저장소들이
공통으로 갖출 것을 정합니다. 틀은 [`templates/example-repo/`](../templates/example-repo/) 에 있습니다.

참고 구현: [dicy2-stepchorus](https://github.com/joonhyungbae/dicy2-stepchorus) (파이썬),
[mediapipe-shadowpatch](https://github.com/joonhyungbae/mediapipe-shadowpatch) (브라우저),
[webaudio-voiceface](https://github.com/joonhyungbae/webaudio-voiceface) (브라우저, 조작 화면과 전시 화면 둘),
[servo-clothdance](https://github.com/joonhyungbae/servo-clothdance) (브라우저에서 정한 값을 아두이노로 내보낸다),
[webgl-liquidbody](https://github.com/joonhyungbae/webgl-liquidbody) (브라우저, WebGL 셰이더 한 장으로 그린다),
[mediapipe-dancereply](https://github.com/joonhyungbae/mediapipe-dancereply) (브라우저, 작가가 만든 그림·소리를 폴더에서 읽어 쓴다)

## 시작하는 법

빈 폴더에서 맨손으로 시작하지 않습니다. **틀을 복사해서 엽니다.** 그래야 `AGENTS.md` 가
처음부터 들어 있고, 어느 도구로 열어도 같은 규칙을 읽습니다.

```bash
git clone https://github.com/joonhyungbae/opencircuit
cp -r opencircuit/templates/example-repo <대표기술>-<의도>
cd <대표기술>-<의도> && git init
```

그다음 자리표시자(`<...>`)를 채웁니다. 참고 구현은 [dicy2-stepchorus](https://github.com/joonhyungbae/dicy2-stepchorus) 입니다.

## 이름

`대표기술-의도`. 소문자와 하이픈 하나만 쓰고 24자 안쪽으로 둡니다.

- **대표기술**은 그것을 바꾸면 작품이 달라지는 소프트웨어 하나입니다. 교체 가능한 부품은
  이름에 넣지 않습니다. 기술을 둘 적지 않습니다.
- **의도**는 작품이 하려는 일을 영어 한 덩어리로 씁니다. `stepchorus`, `silhouette`, `liquidbody`.
- 폴더 이름도 저장소 이름 그대로 둡니다. 파이썬 코드는 하이픈 없는 패키지 폴더에 넣어
  `import` 에 하이픈이 닿지 않게 합니다.

## 갖출 파일

| 파일 | 무엇 |
|---|---|
| `README.md` | 사람이 읽는 안내. 아래 「README 차례」를 따른다 |
| `AGENTS.md` | AI 에이전트용 인수인계. Cursor·Claude·Codex 가 모두 이 이름을 읽는다 |
| `CLAUDE.md`, `.cursor/rules/*.mdc` | AGENTS.md 를 가리키는 두세 줄 |
| `install.sh`, `install.ps1` | 한 줄 설치. 받기·환경·의존성·필요한 자료까지 |
| `start.sh`, `start.ps1` | 한 줄 실행. 환경을 알아서 찾고, 없는 것은 대신 챙긴다 |
| `environment.yml` | conda 환경. 모든 예제는 conda 로 돈다. 파이썬 패키지가 없어도 파이썬만 적어 둔다. pip 로만 받는 것은 `pip:` 아래에 |
| `scripts/conda.sh`, `scripts/conda.ps1` | conda 찾기와, 없을 때 Miniforge 깔기. install·start 가 불러 쓴다 |
| `LICENSE` | OpenCircuit License v1.0 (소스 공개) |
| `NOTICE.md` | 제3자 구성요소와 라이선스. 받아 쓰는 자료의 출처도 |
| `docs/notes.md` | 왜 이렇게 만들었는지. README 에서 뺀 긴 설명 |
| `.gitignore` | 큰 자료(소리·영상·모델·엔진)는 커밋하지 않는다 |
| `.gitattributes` | 줄바꿈 고정. `.sh` 가 CRLF 로 받히면 맥에서 `bad interpreter` 로 죽는다 |

## 코드 구성

언어와 무관하게 **한 파일이 한 가지만** 합니다. 파이썬이면 이 꼴을 따릅니다.

```text
run.py                 시작하는 자리. 인자를 읽고 조각들을 이어 붙인다. 로직을 쌓지 않는다
<패키지>/
├── settings.py        만지는 숫자가 전부 여기. 다른 파일에 숫자를 하드코딩하지 않는다
├── <입력>.py          감지·입력. 바깥 세계를 몇 가지 사건으로 바꿔 내보낸다
├── <결정>.py          무엇을 할지 고른다. 작품의 성격이 정해지는 자리
├── <출력>.py          소리·화면·모터로 내보낸다
├── app.py             사건 하나가 들어왔을 때 벌어지는 일. 짧게 유지한다
├── server.py          대시보드 서버 (있으면)
└── web/               화면. index.html · style.css · app.js · vendor/
```

- **입력은 사건으로 바꿉니다.** 카메라든 센서든 마우스든 같은 사건을 내보내면 나머지는
  그대로 돕니다. 이것이 작가가 입력을 바꿔 가며 실험할 수 있게 하는 핵심입니다.
- **결정 자리는 갈아 끼울 수 있게 둡니다.** 엔진을 쓰면 규칙 쪽을 대체 경로로 남깁니다.
  엔진이 없거나 늦어도 작품은 계속 돌아야 합니다.
- **대시보드는 상태를 보여 주고 값을 바꾸는 곳**입니다. 작가가 코드를 고치지 않고 만질 수
  있는 값은 전부 여기로 올립니다.
- 큰 자료(소리·영상·모델·엔진)는 받아 쓰고 커밋하지 않습니다.

### 브라우저에서 도는 예제

계산이 브라우저 안에서 끝나는 예제(MediaPipe 웹판 등)는 파이썬 패키지가 필요 없습니다.
그때는 이 꼴입니다. 참고 구현은 mediapipe-shadowpatch 입니다.

```text
serve.py               시작하는 자리. 표준 라이브러리 서버로 web/ 를 띄우고 공통 명령을 처리한다
fetch_<자료>.py        모델·영상을 받는다. 표준 라이브러리만, 안 되면 curl
web/
├── settings.js        만지는 숫자가 전부 여기. 조절판 항목도 여기서 만든다
├── <입력>.js · <결정>.js · <출력>.js
├── app.js             한 프레임에 벌어지는 일과 조절판
└── vendor/            라이브러리. CDN 대신 저장소에 넣는다
```

- `environment.yml` 에는 파이썬만 둔다. 그래도 conda 환경으로 켠다.
- 정적 서버는 `Cache-Control: no-store` 를 보낸다. 그러지 않으면 작가가 고친 파일 대신 옛 모듈이 돈다.
- 조절판 값을 브라우저에 남긴다면 `settings.js` 의 처음 값이 바뀌었을 때 남은 값을 버린다.
- `--offline N` 은 가짜 입력으로 N초를 녹화해 서버로 보내 `out.mp4` 로 적는다.
- 설치 없이 보는 주소(GitHub Pages)를 둘 수 있다. 커밋하지 않는 모델은 Actions 가 올리기 직전에 받는다.

## 공통 명령

예제마다 다르면 설명도 검증도 매번 달라집니다. 아래는 모든 예제가 같게 둡니다.

| 명령 | 하는 일 |
|---|---|
| `./start.sh` | 장비가 있으면 장비로, 없으면 대신 켠다. 브라우저를 연다 |
| `./start.sh --sim` | 장비 없이 가짜 입력으로 돈다 |
| `./start.sh --offline N` | 출력 장치 없이 N초를 파일로 적는다. 검증에 제일 빠르다 |
| `./start.sh --host 0.0.0.0` | 폰이나 다른 컴퓨터에서 대시보드를 본다 |
| `./start.sh --port 7001` | 포트를 바꾼다 |

## README 차례

1. 저장소 이름과 **무엇이 일어나는지** 세 문장
2. 무엇이 필요한지 한 문단 (장비와 핵심 기술)
3. **만든 배경** 한 문단 — 멘토링에서 나온 예제라는 사실을 적는다.
   **작가 이름과 아직 발표되지 않은 작품 구상은 본인 확인을 받기 전에는 쓰지 않는다.**
   전시가 끝나 작품이 공개된 뒤에 본인이 원하면 그때 이름과 작품명을 넣는다
4. **깔기** — 맥과 윈도우 각각 한 줄
5. **켜기** — 한 줄. 무엇이 저절로 되는지도 적는다
6. **화면에서 보는 것** — 칸마다 한 줄
7. **바꾸는 자리** — 쉬운 것부터. 첫 자리는 숫자가 모인 파일
8. **안 될 때** — 표. 실제로 막히는 자리만
9. **더 들어가기** — 파일 구조, 핵심 기술, `docs/notes.md` 링크
10. **쓰는 것과 라이선스**
11. 접어 둔 영어 요약

쓰지 않는 것: 이미지, 배지, 코딩을 못해도 괜찮다는 식의 달래는 문장, 할 일 개수를 세는 문장,
라이선스를 괄호로 요약한 꼬리말(저장소 설명에도 넣지 않는다), 긴 대시(—),
「~가 아니라 ~」 같은 대조 구문.

## 지킬 것

- **언제나 conda 로 돕니다.** 설치는 conda 환경을 만들고, 켜기는 `conda run --no-capture-output -n <환경>` 으로
  그 환경 안에서 합니다. conda 가 없으면 venv 나 시스템 파이썬으로 넘어가지 않고 Miniforge 를
  `~/miniforge3` 에 깝니다(관리자 권한·셸 설정 없이). `requirements.txt` 와 venv 길은 두지 않습니다.
- **인터넷 없이 떠야 합니다.** 전시장에서 네트워크가 끊깁니다. CDN, 외부 폰트, 외부 스크립트를
  쓰지 않고 필요한 파일은 저장소에 넣습니다.
- **없어도 돌아가야 합니다.** 카메라가 없으면 시뮬레이션, 스피커가 없으면 파일로 녹음,
  엔진이 없으면 규칙으로. 어느 하나가 빠져도 멈추지 않습니다.
- **숫자는 한 파일에.** `settings.py` 처럼 만지는 값만 모은 파일을 둡니다. 다른 파일에 숫자를
  하드코딩하지 않습니다.
- **주석과 문서는 한국어.** 영어 요약은 README 맨 아래 접힌 자리에만 둡니다.
- **큰 자료는 받아 씁니다.** 소리·영상·모델·엔진은 설치 스크립트가 받아 오고 커밋하지 않습니다.
  받은 자료의 출처와 라이선스는 받을 때 파일로 적습니다.
- **라이선스는 소스 공개**입니다. 오픈소스라고 부르지 않습니다. 작품은 자유, 강의 사용과
  판매는 사전 문의입니다.

## 규칙을 고치는 법

새 예제를 만들다 더 나은 방법이나 함정을 찾으면 **그 저장소에만 적고 끝내지 않습니다.**
이 문서와 틀에 반영합니다. 실제로 그렇게 더해진 것들입니다.

- uvicorn 에 `websockets` 가 없으면 WebSocket 이 404 가 된다
- 매 바퀴 `sleep(한 블록)` 으로는 실시간을 못 맞춘다. 다음에 깨어날 시각을 정해 두고 맞춘다
- 리눅스의 `open` 은 맥의 그것과 다른 명령이다
- 같은 프로그램을 여러 번 켜면 포트가 겹친다. 비어 있는 포트를 찾아 쓴다
- `.ps1` 은 UTF-8 BOM 을 붙여 저장한다. BOM 이 없으면 한국어 윈도우의 PowerShell 5.1 이 CP949 로 읽어
  한국어가 깨지고 문자열이 꼬인다. 줄바꿈은 `.gitattributes` 로 고정한다(.sh 는 LF, .ps1 은 CRLF)
- conda 는 터미널 설정을 읽지 않는 자리(curl | bash, 더블클릭, 자동 시작)에서도 찾아야 한다.
  `type -P conda` 다음에 흔한 설치 위치(`~/miniforge3`, `~/miniconda3`, `~/anaconda3` 등)를 차례로 본다
- Miniforge 설치 파일은 이름이 `.sh` 로 끝나지 않으면 「bash 로 실행하라」며 멈춘다
- 맥에 git 이 없으면 `git` 을 치는 순간 개발 도구 설치 창이 뜬다. 설치 스크립트는 git 이 없으면 압축 파일로 받는다
- 맥의 python.org 파이썬은 인증서가 없어 https 를 못 여는 일이 있다. 내려받기는 실패하면 curl 로 다시 받는다
- `python3 -m http.server` 는 브라우저 캐시를 막지 않는다. 고친 JS 가 안 보이면 이것부터 의심한다
- 브라우저 모듈 안의 상대 경로는 그 모듈 기준으로 풀린다. `vendor/` 처럼 페이지 기준 자리는 `document.baseURI` 로 부른다
- MediaPipe 웹판을 GPU 로 돌리면 관절은 잡히는데 분리 마스크가 전부 0 인 환경이 있다. 기본은 CPU
- **MediaPipe 웹판은 사용 기록을 구글로 보낸다**(`odml.pa.googleapis.com/v1/log`, 60초마다와 모델을 닫을 때). 1분이
  안 되는 시험에서는 드러나지 않는다. 페이지에서 그 주소로 가는 fetch 만 막는다. 「밖으로 보내지 않는다」 시험은 1분 넘게 돌린다
- 정적 서버는 구간 요청(Range)에 206 으로 답해야 한다. 파이썬 기본 서버는 못 해서 브라우저가 영상의 한 시점으로 넘어가지 못한다(늘 0초)
- 생성 모델이 만든 영상은 키프레임이 처음에 하나뿐인 경우가 많다. 넘기기가 갈수록 느려지므로 `-g 4 -bf 0` 으로 다시 인코딩한다
- 큰 생성 자료(영상 등)는 저장소의 릴리스에 올리고 설치 스크립트가 받는다
- 이미지를 더해 섞을 때 8비트 틀을 쓰지 않는다. 겹친 곳이 잘리고 옅은 곳이 하얗게 튄다. RGBA16F 를 쓴다
- API 키(APIFrame 등)는 저장소 밖(`~/.opencircuit/` 이나 환경 변수)에서 읽기만 하고, `.gitignore` 에 키 파일과 `.env` 를 둔다
- 브라우저 예제에서 입력 분석을 화면 그리기(requestAnimationFrame)에 묶지 않는다. 조작 창이 다른 창에 가려지면
  그리기가 멈춰 그동안의 입력을 놓친다. 소리는 AudioWorklet 에서 받는다
- 소리를 고정 문턱으로 가르지 않는다. 녹음과 방마다 바닥 소음이 다르다. 바닥 소음을 따라가는 문턱을 쓴다
- 그 바닥은 천천히 올라가고 빨리 내려와야 한다. 빨리 올라가게 두면 큰 소리가 그대로 바닥이 되어 다음 타격을 놓친다
- 타격의 세기는 소리가 커지는 순간이 아니라 봉우리에서, 배수가 아니라 dB 로 잰다. 올라가는 중에 재면 늘 약하게 나온다
- 마이크를 열 때 echoCancellation·autoGainControl 을 끈다. 켜 두면 타악기의 봉우리가 깎여 세게 친 것과 살살 친 것이 같아진다
- 모터가 붙는 작품은 화면과 모터가 같은 숫자를 쓰게 한다. 부품이 오기 전에 각도를 정해 둘 수 있다
- gh 로 저장소를 만들면 기본 가지가 master 로 올라갈 수 있다. Pages 환경이 그 가지만 허락해 배포가 거절된다. 먼저 main 으로 바꾼다
- 다른 예제의 Pages 워크플로를 베껴 오면 그 저장소의 내려받기 스크립트 이름이 남는다. 배포가 그 줄에서 멈춘다
- 사람의 모양만 쓰는 작품은 관절 모델이 아니라 분리(segmenter) 모델을 쓴다. 가볍고 마스크가 매끄럽다
- 2D 그림판을 셰이더의 텍스처로 올리면 위아래가 뒤집힌다. 화면 좌표와 같은 방향으로 읽는다
- 마스크를 한 번에 크게 흐리면 네모진 자국이 남는다. 둥글게 돌며 여러 번 읽어 흐린다
- 브라우저는 폴더 안을 들여다볼 수 없다. 작가가 넣은 자료는 작은 파이썬 스크립트가 목록으로 만들고,
  start 가 켤 때마다 그것을 돌린다. 작가는 파일만 넣으면 되게 한다
- 작가가 만든 그림·소리가 들어갈 자리는 비워 두고 자리표시자로 돌린다. 그림이 없다고 멈추면
  작가는 그림을 다 그린 뒤에야 흐름을 볼 수 있다
- 움직임을 한 프레임의 차이로만 재면 프레임이 느린 기계에서 작게 나온다. 1초치로 환산한다
- 화면이 둘(조작·전시)이면 같은 브라우저의 BroadcastChannel 로 상태 숫자만 보낸다. 관객의 녹음·영상은 보내지 않는다
- 시험용 영상은 온몸이 보이고 머리·팔이 잘리지 않은 것을 고른다. 위키미디어의
  「Jumping jacks and burpees」(CC BY-SA 4.0)가 팔 벌리기·웅크리기·돌아서기를 다 담고 있다
